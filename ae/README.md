# タイムリサイズ / TIME RESIZE

After Effects のタイムラインに並べた動画素材を、**そのまま尺で指定してリサイズする**スクリプトです。

`time-resize.jsx` の1ファイルだけで動きます。

---

## なにが違うのか

AE にも時間伸縮はあります。タイムラインでレイヤーバーの端を **Ctrl（Windows）/ Command（Mac）を押しながらドラッグ**すると、トリムではなく時間伸縮になります。ただしこの方法だと、

- 伸縮率が `137.42%` のような半端な数字になる
- 「3秒ちょうどにしたい」と思っても、伸縮率を自分で逆算するしかない
- 複数のクリップを同じ尺にそろえるには、1本ずつ手で合わせることになる
- 伸ばすとイン点が動くことがあり、並べ直しが要る

このスクリプトは、そこを**尺のほうから指定**できるようにしたものです。伸縮率は自動で逆算されます。

---

## 入れかた

`time-resize.jsx` を、AE のインストール先の `ScriptUI Panels` フォルダに入れます。

| OS | 場所 |
|---|---|
| Windows | `C:\Program Files\Adobe\Adobe After Effects <バージョン>\Support Files\Scripts\ScriptUI Panels\` |
| macOS | `/Applications/Adobe After Effects <バージョン>/Scripts/ScriptUI Panels/` |

AE を再起動すると、**ウィンドウ** メニューの一番下あたりに `time-resize.jsx` が出ます。選ぶとパネルが開くので、他のパネルと同じようにドッキングできます。

置き場所を変えたくない場合は、**ファイル > スクリプト > スクリプトファイルを実行** からでも使えます（この場合は毎回開き直しになります）。

> ファイルの読み書きもネットワークもしないので、環境設定の「スクリプトによるファイルへの書き込みとネットワークへのアクセスを許可」は不要です。

### macOS の場合

`ScriptUI Panels` は `/Applications` の中なので、コピーするときに **管理者パスワードを聞かれます**。正常な動作なので、そのまま入れてください。AE 2026 なら実際のパスはこうなります。

```
/Applications/Adobe After Effects 2026/Scripts/ScriptUI Panels/
```

ターミナルから入れるなら：

```bash
sudo cp ae/time-resize.jsx "/Applications/Adobe After Effects 2026/Scripts/ScriptUI Panels/"
```

`~/Library/Application Support/Adobe/` の下に置く方法は**使えません**。あの場所を読むのは CEP 拡張機能で、ScriptUI パネルのスクリプトは対象外です。管理者権限を使いたくない場合は、上の「スクリプトファイルを実行」で開いてください。

ブラウザでダウンロードしたファイルには macOS が検疫属性を付けます。AE が読めない・無反応のときはこれを外します。

```bash
xattr -d com.apple.quarantine "/Applications/Adobe After Effects 2026/Scripts/ScriptUI Panels/time-resize.jsx"
```

### 対応バージョンについて

ExtendScript と ScriptUI パネルは AE 2026 でも現役です（AE 向けの UXP パネルはまだ提供されていないため、パネルは引き続き ExtendScript が標準）。Apple Silicon でもそのまま動きます。

## 使いかた

タイムラインで**尺を変えたいレイヤーを選んでから**、パネルのボタンを押します。複数選択できます。

### 目標の尺にする

数値を入れて `適用`。単位は **秒** と **フレーム** を切り替えられます（切り替えると値も換算されます）。

`今の尺を読む` を押すと、選択中の一番上のレイヤーの尺が入力欄に入るので、そこから少し変える、という使い方ができます。

### 尺を合わせる

| ボタン | 動き |
|---|---|
| `ワークエリア` | 選択したレイヤーを、ワークエリアの長さにそろえる |
| `コンポ全長` | コンポジションの長さいっぱいにそろえる |
| `一番上の選択レイヤーに合わせる` | 一番上のレイヤーを**基準**にして、残りの選択レイヤーをその尺にそろえる |

`開始位置も合わせる` にチェックを入れると、尺だけでなく**イン点も**合わせ先の頭にそろいます。3本のクリップをワークエリアにぴったり重ねる、といったことが1回でできます。

> 基準レイヤーに合わせるときだけは、ぴったり一致させるために「フレーム単位にそろえる」を無視します。

### 伸縮の基準

伸ばしたり縮めたりしたときに、**どこを動かさないか**です。

- **イン点を固定** — 頭の位置が変わらない。並べたクリップの順番を崩したくないとき（既定）
- **現在の時間を固定** — 再生ヘッドの位置に出ている絵が変わらない。プレビューしながら速度を詰めるとき
- **アウト点を固定** — 終わりの位置が変わらない。「ここで終わる」が決まっているとき

`フレーム単位にそろえる` を入れておくと、目標の尺が最寄りのフレームに丸められ、1フレーム未満の端数が出ないようにトリムで詰めます。

### 結果

実行するとパネル下部に、レイヤーごとの `伸縮率の変化` と `結果の尺` が出ます。処理できなかったレイヤーは `×` 付きで理由が出ます。

**取り消しは Ctrl/Command + Z を1回**です。何レイヤーまとめて処理しても1回分にまとまっています。

## 知っておくこと

- **キーフレームも一緒に伸び縮みします。** AE の時間伸縮の仕様どおりで、レイヤーに付けた位置やスケールのアニメーションも同じ比率で伸縮します
- **音声のピッチが変わります。** 時間伸縮は音を単純に引き伸ばすので、遅くすると低く、速くすると高くなります。ピッチを保ちたい場合は、音声を別レイヤーに分けて伸縮対象から外してください
- **タイムリマップが有効なレイヤーは処理しません。** 時間伸縮と併用すると結果が読めなくなるため、スキップして理由を出します
- **カメラとライトは対象外です。** 時間伸縮の概念がありません
- **ロックされたレイヤーも処理できます。** 一時的に解除して、終わったらロックし直します
- **伸縮率は 1%〜10000%** が AE の上限です。振り切ると目標の尺に届かないので、その旨がログに出ます
- 速度を落としたときのカクつきは、レイヤーの**フレームブレンド**を入れると軽減できます

---

## ファイルについて

`time-resize.jsx` は **BOM 付き UTF-8** で保存されています。ExtendScript は BOM が無いと環境によっては日本語を別の文字コードとして読んでしまうので、編集するときは BOM を落とさないようにしてください。

中身は素の ExtendScript（ES3 相当）で、外部ライブラリには依存していません。
