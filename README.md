# ゆめテープ / YUMETAPE

いつもの景色を、**VHS・ホラー・ドリームコア**の映像に変えて撮るカメラです。

**→ https://maigohasegawa.github.io/yumetape/**

エフェクトはリアルタイムでかかり、**撮った時点でその見た目**になっています。あとから加工する必要はありません。写真も動画も撮れます。

ブラウザだけで動きます。インストールも会員登録も不要で、映像はすべて端末の中で処理され、どこにも送信されません。

---

## 使い方

1. **Safari**（iPhone）や Chrome で上のURLを開く
2. 「カメラを起動する」→ カメラへのアクセスを許可
3. 画面下のプリセットを選ぶ
4. 丸いボタンで録画開始／停止。`PHOTO` に切り替えると写真
5. 撮影後の「共有 / 写真に保存」から写真アプリへ

### アプリとして使う

Safariの共有ボタン（□に↑）→ **「ホーム画面に追加」** で、ブラウザのバーが消えた全画面のアプリになります。追加後は電波がなくても起動でき、エフェクト設定も記憶されます。

Android・PCのChromeなら、起動画面に出る「アプリとしてインストール」ボタンから入れられます。

## リレーVlog

10秒ずつ撮って次の人にまわし、1本の動画を作る機能です。**できあがった動画そのものがバトン**で、AirDropやメッセージで次の人に渡します。サーバーを使わないので、リンクで共有する形ではありません。

1. 1人目が「リレー → 新しく始める」で10秒撮る
2. できた動画を次の人に渡す
3. 受け取った人は「リレー → 受け取った動画を続ける」でその動画を選ぶ
4. これまでの映像が再生され、残り3秒からカウントダウン。終わると自動で自分の番になり、10秒経つと止まる
5. 以降くり返し

仕組みとしては、受け取った動画を録画中のキャンバスに流し込み、終わったらそのままカメラ映像に切り替えています。録画対象は最初から最後まで同じキャンバスなので、1本の続いた動画として書き出されます。

- **前の人の映像にはエフェクトをかけ直しません**。各自の区間はそのときの見た目のまま残ります
- カウントダウンはキャンバスの外に描いているので、映像には焼き込まれません
- 縦向き720×1280に固定されます（全員のコマをそろえるため）
- 音声は、再生パートは元動画の音、自分の番はマイクに自動で切り替わります
- **まわすたびに映像は少しずつ荒れます。**ダビングを重ねたVHSと同じ現象です

## 撮影の機能

- **写真・動画の読み込み** — 撮影済みの写真や動画を読み込んで、同じエフェクトをかけられます。読み込んだ動画は再生しながら書き出せ、最後まで行くと自動で止まります。写真を読み込んで録画すると、ノイズやグリッチだけが動く映像になります
- **録画の一時停止** — ストップウォッチのラップのように、録画を止めずに区切れます。止めている間の映像は記録されないので、1本のファイルの中で場面が切り替わる動画になります（Vlog向け）
- **録画速度** — 0.25x / 0.5x / 1x / 2x / 4x。標準以外は録画停止後に変換が入り、音声なしになります
- **GLITCHボタン** — 押している間だけ映像が激しく壊れます。画面タップでも一瞬グリッチ
- **カムコーダー表示** — `● REC` / 日付 / タイムコード / `SP` を映像に焼き込み（OFF可）
- 前面／背面カメラの切り替え、カメラ個別選択（超広角・望遠）、解像度切り替え、ミラー、音声収録の有無

## エフェクト

カメラ映像をWebGLのシェーダーで加工しています。すべて設定画面から0〜1で個別に調整できます。

**VHS系** — クロマブリード（YIQ色空間で色差信号だけ横に引き伸ばす）、RGBシフト、走査線、インターレース、テープ揺れ、ヘッドスイッチングノイズ（画面下部の帯）、テープの傷、残像、コマ落ち

**ホラー系** — 縦の同期ズレ（画面が流れて黒帯が横切る）、明滅、色味（暗視の緑・夜の青・非常灯の赤）、暗部ほど強く乗るグレイン

**ドリーム系** — ブルーム、ソフトフォーカス、褪せ、光漏れ、きらめき、周辺ほど強いレンズの色ズレ、レンズのふくらみ、うねり、低画質デジカメ、対称（左右／上下／4分割）

**レンズ系** — 魚眼（ふくらみ／へこみ）、ドアスコープ（丸く切り抜く）、ドロステ（無限の入れ子）とそのひねり

**グリッチ系** — ブロック置換、スライスずれ、波打ち歪み、色反転ノイズ、自動グリッチ

### 細部について

**テープの傷（細い白線）** は1ピクセル幅で、出現の有無・縦位置・長さ・明るさをすべて毎回ランダムに決めています。格子に乗らないので規則性が見えません。

**ブロックグリッチ** は細かいモザイク単位で、ずらす量もブロック格子にスナップさせています。切り出した四角がそのまま隣にはまったように見えます。色反転だけは粗い格子で数を絞り、粒が散らばらないようにしています。

**魚眼** は縦横比を補正した空間で半径を測っているので、横長でも縦長でもふくらみが真円になります。画面の隅を半径1として、そこでの縮み具合をスライダーで決めます。マイナスに振ると糸巻き型（へこみ）になります。

**ドロステ** は前のコマを縮小・回転して中央にはめ込んでいます。次のコマではその絵の中にさらに前の絵が入っているので、続けるほど奥へ入れ子が伸びていきます。「ひねり」を上げると螺旋になります。ビデオカメラを自分のモニターに向けたときに起きる現象と同じ仕組みです。

ドリーム系の重い処理（ブルーム・ソフトフォーカス・色ズレ）と、レンズ系のドロステ・ドアスコープは、値が0のときはシェーダー側で丸ごと飛ばしているので、使わないプリセットでは負荷が増えません。

## 構成

ビルド不要の静的ファイルだけで動きます。

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JS・シェーダーすべて） |
| `manifest.webmanifest` / `sw.js` / `icons/` | ホーム画面に追加してアプリとして使うための一式 |

`sw.js` がアプリ本体をキャッシュするので、2回目以降はオフラインでも起動します。**本体を更新したら `sw.js` の `CACHE` のバージョンを上げてください。**

## 動作環境

- iOS 17以降のSafariでは動画は**MP4**、非対応環境ではWebMで保存されます
- カメラの利用には `https://` でのアクセスが必要です
- 重い・カクつく場合は、設定から解像度を下げるか「色にじみ」「残像」「ブルーム」を下げてください

## 同じ場所にあるもの

アプリ本体とは関係のないツールが、同じリポジトリに置いてあります。

### LAYER SONG

`lyric-layer-tool_1.html` は別のツール（**LAYER SONG**）です。1曲の歌詞を3つのトラックに分解し、それぞれ単独でも成立しつつ、3曲を重ねて歌うと元の1曲が浮かび上がる——そんなギミック曲づくりを補助します。このリポジトリが元々そのために作られたものだったので、そのまま置いてあります。

**→ https://maigohasegawa.github.io/yumetape/lyric-layer-tool_1.html**

### タイムリサイズ（After Effects用）

`ae/time-resize.jsx` は After Effects 用のスクリプトです。タイムラインに並べた動画素材を、伸縮率ではなく**尺のほうから**リサイズできます。「3秒ちょうどにする」「ワークエリアに合わせる」「他のクリップと同じ長さにそろえる」といった指定ができ、複数レイヤーをまとめて処理できます。伸縮してもイン点・現在の時間・アウト点のどれかは動かないように選べます。

ブラウザでは動きません。AE の `ScriptUI Panels` に入れて使います。→ **[ae/README.md](ae/README.md)**
