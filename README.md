# lyric

制作補助用のシングルファイル・ウェブツール置き場です。どれもビルド不要で、HTMLを1枚開くだけで動きます。

| ファイル | 内容 |
|---|---|
| `index.html` | 2つのツールへのランチャー |
| `lyric-layer-tool_1.html` | LAYER SONG — 1曲の歌詞を3トラックに分解し、重ねると元の歌詞に戻るギミック曲を作るツール |
| `vhs-glitch-cam.html` | VHS / GLITCH CAM — カメラ映像にVHS風エフェクトとグリッチをリアルタイムで乗せて撮影するツール（PWA） |
| `manifest.webmanifest` / `sw.js` / `icons/` | VHS / GLITCH CAM をアプリとして使うためのPWA一式 |

## VHS / GLITCH CAM

iPhone（iOS Safari）で動くカメラアプリです。カメラ映像をWebGLシェーダーで加工し、**エフェクトが焼き込まれた状態**で写真・動画を保存します。後処理は不要です。

### 使い方

1. **HTTPSで**ページを開く（下の「公開方法」参照）
2. 「カメラを起動する」→ カメラへのアクセスを許可
3. 下部のプリセットを選ぶ（CLEAN / VHS 1984 / WORN TAPE / CAMCORDER 8mm / GLITCH / DATAMOSH / BROKEN TV / MONO SECURITY）
4. VIDEO / PHOTO を切り替えてシャッターを押す
5. 撮影後の画面で「共有 / 写真に保存」→ iOSの共有シートから写真アプリへ保存

### 操作

- **シャッター** — VIDEOモードで録画開始／停止、PHOTOモードで静止画
- **GLITCH** — 押している間だけ映像が激しく壊れる（離すと戻る）
- **プレビューをタップ** — 一瞬だけグリッチ
- **⚙** — エフェクト設定（各パラメータをスライダーで調整）
- **⇄** — 前面／背面カメラの切り替え
- **⤓** — 直前に撮影したものを再表示

### プリセット

**VHS** — `CLEAN` / `VHS 1984` / `すり切れテープ` / `8mm ホームビデオ`
**ホラー** — `心霊ビデオ` / `監視カメラ` / `暗視カメラ` / `呪いのテープ`
**グリッチ** — `GLITCH` / `DATAMOSH`

### エフェクト

- **VHS系** — クロマブリード（YIQ色空間で色差信号だけ横に引き伸ばす）、RGBシフト、走査線、インターレース、テープ揺れ、ヘッドスイッチングノイズ（画面下部の帯）、テープの傷（細い白線）、残像（フレームフィードバック）、コマ落ち
- **ホラー向け** — 縦の同期ズレ（画面が流れて黒帯が横切る）、明滅、色味（暗視の緑・夜の青・セピア・非常灯の赤）、暗部ほど強く乗るグレイン
- **グリッチ系** — ブロック置換、スライスずれ、波打ち歪み、色反転ノイズ、自動グリッチ（頻度調整可）

すべて設定シートから0〜1で個別に調整できます。

**細い白線（テープの傷）** は1ピクセル幅で、出現するかどうか・縦位置・長さ・明るさをすべて毎回ランダムに決めています。格子に乗らないので規則性が見えません。

**ブロックグリッチ** は細かいモザイク単位で、ずらす量もブロック格子にスナップさせています。切り出した四角がそのまま隣にはまったように見え、四角が大きすぎて安っぽく見えるのを避けています。**色反転ノイズ** だけは粗い格子で数を絞り、粒が散らばらないようにしています。

「カムコーダー表示」をONにすると、`● REC` / 日付 / タイムコード / `SP` が映像に焼き込まれます（設定でOFF可）。

### 公開方法

`getUserMedia` はHTTPSでしか動きません。GitHub Pagesで配信するのが手軽です。

1. リポジトリの Settings → Pages → Source を `main` ブランチのルートに設定
2. `https://<ユーザー名>.github.io/lyric/` を開くとランチャー、
   `https://<ユーザー名>.github.io/lyric/vhs-glitch-cam.html` がカメラ本体

### アプリとして使う（PWA）

このツールはPWAとして作ってあるので、ホーム画面に追加すると **ブラウザのバーが消えて全画面のアプリになります**。App Store も Xcode も不要です。

**iPhone / iPad**

1. Safariで `vhs-glitch-cam.html` を開く
2. 共有ボタン（□に↑）→ **「ホーム画面に追加」**
3. 追加されたアイコンから起動する

アイコンから起動すると次のようになります。

- Safariのアドレスバー・ツールバーが消えて全画面
- 起動時にVHSカセットのアプリアイコンとスプラッシュ（黒背景）
- Service Workerが本体をキャッシュするので、**2回目以降は機内モード・電波なしでも起動**
- エフェクト設定（プリセット・各スライダー・ミラー・音声・OSD）は端末に保存され、次回起動時に復元

**Android / PC（Chrome・Edge）**

起動画面に「アプリとしてインストール」ボタンが出るので、それを押せばインストールされます。

> ホーム画面に追加した直後は、カメラの使用許可をもう一度聞かれます（Safariとは別のアプリ扱いになるため）。

> **更新時の注意**：`vhs-glitch-cam.html` を編集したら、`sw.js` の `CACHE` の値（`vhscam-v1`）を上げてください。古いキャッシュが残ったままになるのを防げます。

### 動作要件・注意

- iOS 17以降のSafariでは動画は**MP4**、非対応環境ではWebMで保存されます
- 録画中は画面スリープを抑止します（Screen Wake Lock対応端末のみ）
- 重い・カクつく場合は、設定シートで解像度を下げるか「色にじみ」「残像」を下げてください
- 保存・アップロードは一切行いません。映像は端末内で処理され、共有シートから自分で保存するまでどこにも残りません
